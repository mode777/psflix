# Stage 7 — Polish

Sweep over the existing UI to make it feel like a flagship console dashboard. No new features; everything here is refinement.

## Goal

The app feels calm, focused, and quick. No jank, no broken states, no missing affordances.

## Scope

### Loading & empty states

- [ ] Every `useQuery` / `useInfiniteQuery` returns a skeleton (no flash of empty content).
- [ ] Empty results render the empty state for at least 300 ms (avoid a jarring "0 results → 5 results" flicker).
- [ ] Cover images with `loading="lazy"` and `decoding="async"`.

### Error boundaries

- [ ] `src/components/ErrorBoundary.tsx` wrapping each route via `src/App.tsx`.
- [ ] Global `QueryClient` error handler in `src/main.tsx` — toasts on errors (via a tiny toast module).
- [ ] On PB network errors, show a "Couldn't reach the server" panel with a Retry button.

### Keyboard navigation

- [ ] Browse grid is arrow-key navigable: Up/Down/Left/Right moves the focused card.
- [ ] `Enter` opens the focused card.
- [ ] `Esc` closes any open modal/lightbox.
- [ ] Carousel: `Left` / `Right` arrow keys scroll the active carousel.
- [ ] Visible focus rings (the design system uses `border-primary` on focus; ensure tab order is sensible).

### Accessibility

- [ ] Every icon-only button has a unique `aria-label`.
- [ ] Modals trap focus and restore it on close.
- [ ] Lightbox uses `<dialog>` (already does).
- [ ] All images have `alt` text (title for screenshots; cover image falls back to the title).
- [ ] Heading hierarchy is correct: one `<h1>` per route, no skipped levels.

### Animations

- [ ] `200ms` fade-in-up on details view mount (already in mock).
- [ ] Hover transitions are ≤ `300ms` (already on cards).
- [ ] Respect `prefers-reduced-motion` — disable transforms and large animations when set.

### SEO / meta

- [ ] `react-helmet-async` (or equivalent) installed:
  ```bash
  npm install react-helmet-async
  ```
- [ ] Default `<title>PSflix</title>` and `<meta name="description">` in `App.tsx`.
- [ ] Per-details-view `<title>{game.title} | PSflix</title>` and `<meta property="og:image">` from `fileUrl`.

### 404 view

- [ ] Already added in Stage 3; verify it's reachable and styled.

### Code quality

- [ ] No `console.log` left in shipped code.
- [ ] No `any` in `src/` (unless generated by `pocketbase-typegen`).
- [ ] Dead code removed: unused components, unused imports.

## Files to create / edit

- `src/components/ErrorBoundary.tsx`
- `src/components/Toast.tsx` + `src/lib/toast.ts` (tiny module, no `notistack` needed)
- `src/hooks/useArrowKeyNav.ts` (used by the browse grid)
- `src/App.tsx` (wraps routes in `ErrorBoundary`)
- `src/routes/DetailsView.tsx` (add helmet + animation)
- `src/routes/BrowseView.tsx` (add arrow-key nav + skeleton polish)
- `src/styles/index.css` (add `@media (prefers-reduced-motion: reduce)` block)

## Acceptance criteria

- [ ] Lighthouse a11y score ≥ 95 on `/` and `/#/game/<serial>`.
- [ ] No console errors or warnings during a full browse → details → lightbox flow.
- [ ] All routes render in < 100ms after data is cached.
- [ ] Animations are smooth (no dropped frames during scroll on a mid-range laptop).
- [ ] `prefers-reduced-motion` disables transforms.
- [ ] `npm run typecheck && npm run lint` pass.

## Manual verification

1. Walk through browse → details → lightbox on a real PB instance.
2. Resize to mobile (`< 768px`) — check margins, scroll, header.
3. Tab through the page — every interactive element is reachable; focus rings are visible.
4. Toggle `prefers-reduced-motion` in DevTools → confirm animations are disabled.
5. Force a network error (DevTools → Offline) → trigger a refetch → error UI appears.

## Out of scope

- Smart prefetching / preloading (Stage 8 may add).
- Real player/emulator UI (post-v1, per `AGENTS.md`).
- Save state UI (post-v1).
